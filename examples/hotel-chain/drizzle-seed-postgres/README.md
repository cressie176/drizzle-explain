# hotel-chain-drizzle-seed-postgres

The PostgreSQL package of the `hotel-chain` example. See the [shared README](../README.md) for what it demonstrates, how to run it, and the seeding shape — the domain and testing pattern are identical across both databases.

This package uses the `drizzle-explain/postgres` driver and connects to the PostgreSQL service from the repo-root `docker-compose.yml`.
