# hotel-chain-drizzle-seed-mariadb

The MariaDB package of the `hotel-chain` example. See the [shared README](../README.md) for what it demonstrates, how to run it, and the seeding shape — the domain and testing pattern are identical across both databases.

This package uses the `drizzle-explain/mariadb` driver (`ANALYZE FORMAT=JSON`) and connects to the MariaDB service from the repo-root `docker-compose.yml`.
